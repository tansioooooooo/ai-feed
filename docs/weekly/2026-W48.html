📋 週次サマリー

11/16〜11/22 の HN・はてブ記事を分析した。週の中心は Anthropic の Nasdaq 上場（11/19 価格決定、11/20 デビュー）と、同社研究者らによる AI 支援でのリーマン予想「証明」主張、およびその Lean 検証だった。モデルでは GPT-6.2、Gemini 4 Neon、Qwen4-Max、Inkling 2 Mini が出た。開発現場ではエージェントのハーネスや自律開発が話題で、AI が書いたコードのレビューが新たな課題になっている。Nvidia の CEO 交代、楽天証券・KARTE などの大規模情報漏えい、nginx の RCE 脆弱性も目立った。なお、Twitter のデータは今回の分析に含めていない。

🔥 主要トレンド

Anthropic の IPO と存在感の拡大
11/19 に IPO 価格が決まり、11/20 に Nasdaq へ上場した。同社の研究者が AI の未来を予測した記事は「ほぼ全人類が永久に失業する」と報じられた。2028 年の電力の大半がガス・石炭由来になるという報道もあった。AI 企業の資本市場での動きと、電力・環境負荷が注目された。
AI 支援による数学・科学の未解決問題への挑戦
Anthropic 所属の数学者がリーマン予想の証明を主張し、Lean による形式検証や専門家の検証状況が連日取り上げられた。Claude がブラックホール物理の未解決問題 2 件を解いたという話や、AI が設計した CPU「Frostbite」、ナビエ–ストークス方程式の話題も出た。AI が研究の最前線に入りつつある。
新モデルのリリースラッシュ
GPT-6.2（Astra / Sol）、Gemini 4 Neon（Models Engineering Index で 1 位）、Qwen4-Max、Inkling 2 Mini（5.4GB のメモリで動作）が登場した。Gemini の「タスク」モードは日本でも無料で提供が始まり、Meta の Muse なども紹介された。性能競争と、小型・ローカル実行の両方が進んでいる。
AI コーディングエージェントとハーネスの実践
「ワークフローからハーネスへ」という流れが強まり、Claude Code や Codex による自律改善ハーネス、150 行の自作ハーネス、一人でソフトウェア工場を回す andon などの実践記事が多かった。一方で、ハーバード大の研究者らはボトルネックがコードレビューに移ったと報告している。「コードを真面目に読まなくなった」という声もあり、品質管理が課題になっている。
AI が引き起こす雇用・社会・セキュリティ上の摩擦
Google の AI 回答で検索トラフィックが 40% 減った。「SaaS の死」論、AI 生成コンテンツへの反発（Zed のコントリビューションポリシーなど）、Lovable 製アプリでのパスポート情報露出も話題になった。AI によって修正が急がれる「パッチ地獄」が障害を招くという報道もあり、AI は便益とリスクの両面で議論されている。
大規模情報漏えいと重大脆弱性、半導体・ハード動向
楽天証券（最大約 1125 万口座）、三井住友銀、KARTE 経由の漏えい、デジタル庁への不正アクセスなど、国内で漏えいが相次いだ。nginx の認証不要 RCE（CVE-2026-123633 など）や Java4Shell も出た。Nvidia は CEO 交代、会計調査報道、中国モデルへの輸出規制 GPU 使用疑惑で話題になった。
